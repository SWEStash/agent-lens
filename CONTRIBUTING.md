# Contributing to Agent Lens

Agent Lens is maintained by SWEStash and has a single maintainer. Pull requests come only from the maintainer for
now, but bug reports, feature requests, and questions are welcome as issues.

Feedback is welcome:

- **Bugs**: [open a bug report](https://github.com/SWEStash/agent-lens/issues/new?template=bug.yml).
  Say what you did, what you expected, and what happened, and include the output of
  `agent-lens config`. Please don't paste raw transcripts; they can contain secrets.
- **Feature requests and ideas**:
  [open a feature request](https://github.com/SWEStash/agent-lens/issues/new?template=feature.yml)
  that describes the problem you want solved.
- **Security problems**: don't open a public issue. Report it privately through
  [GitHub's security advisories](https://github.com/SWEStash/agent-lens/security/advisories/new).

How issues are triaged, picked up, and closed is in [docs/HOW-WE-WORK.md](docs/HOW-WE-WORK.md).
Working on the code yourself? See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
